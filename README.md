# GameHub
Site desenvolvido em HTML servindo como projeto da disciplina Cultura e Prática DevOps.

O site se trata de uma página voltada para jogos, onde você tem acesso a jogos em destaque e futuros lançamentos.
É possível ser direcionado a página de cada jogo (exceto na seção inicial) clicando na foto do jogo.

O site está hospedado em: https://itshenrickz.github.io/GameHub/
